# Personal Portfolio Website

A responsive personal portfolio website built using React.js and CSS.

## Features
- About Me section
- Education details
- Technical Skills
- Projects showcase
- Contact section
- Responsive design

## Tech Stack
- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/ranisumbul7/-personal-portfolio-using-HTML5-and-CSS3.git
```

### 2. Open the project folder
```bash
cd -personal-portfolio-using-HTML5-and-CSS3
```

### 3. Install dependencies
```bash
npm install
```

### 4. Start the development server
```bash
npm run dev
```
